# 个人规划中心 v2.0 — 交互设计

> 版本：v2.0 ｜ 日期：2026-09-19

## 1. 整体框架

```
┌────────┬──────────────────────────────────────────────┐
│        │  Topbar: 全局搜索(⌕ /)   快速新建(N)   主题☽   │
│ Sidebar├──────────────────────────────────────────────┤
│ 240px  │                                              │
│ 可折叠  │                页面内容区                      │
│        │         max-w-7xl 居中，24px 内边距            │
│ 高亮当前│                                              │
│ 路由    │                                              │
└────────┴──────────────────────────────────────────────┘
```

- **侧边栏分组**：概览（仪表盘）；规划（任务、项目、习惯）；视图入口并入任务页内切换；工具（番茄专注、统计报告）；系统（数据备份、设置）。
- 移动端：侧边栏收起为汉堡抽屉；任务视图切换改顶部滚动标签。
- 图标用 lucide，每项带激活态背景色。

## 2. 页面交互细节

### 2.1 仪表盘 `/`
- 顶部问候（早上好/下午好/晚上好 + 日期 + 一句进度摘要）。
- 4 统计卡（今日待办/即将到期/已完成/进行中），点击跳对应筛选的任务页。
- 今日聚焦列表：勾选即完成（乐观更新 + toast）；无任务时空状态引导快速添加。
- 近 7 天完成趋势面积图；项目进度条列表（点击进项目筛选）。

### 2.2 任务页 `/tasks`（四视图 tab：列表 | 看板 | 日历 | 四象限）
- **顶部工具条**：视图 tab、筛选（项目/状态/优先级/标签/时间）、排序、搜索框。
- **快速添加**：工具条下方常驻输入框，placeholder 提示语法（`试试：明天 提交周报 #固件 @汇报 !1 回车创建`），解析结果实时以小徽章预览在输入框下方。
- **列表**：按日期分组（逾期红点/今天/明天/本周/以后/无日期），行内：勾选框、标题、标签、项目色点、优先级徽章、截止日徽章（逾期红）。点击行开详情侧滑。
- **看板**：5 状态列，卡片可拖拽跨列，落列即 PATCH 状态（dnd-kit），拖拽中列高亮。
- **日历**：月历网格，今日高亮，每格列出当天到期任务（超 3 条折叠"+n"），点任务开侧滑；上月/下月切换。
- **四象限**：紧急重要/重要不紧急/紧急不重要/不紧急不重要四格，任务按规则落格（优先级+是否逾期/今天到期），点任务侧滑中可改优先级/截止日重新落格。
- **详情侧滑**（右侧 480px 面板 + 遮罩）：标题行内编辑、状态/优先级/日期/项目/标签编辑、描述、子任务清单（添加/勾选/删除，显示完成比例）、进度记录时间线、底部完成/删除按钮。Esc 关闭。

### 2.3 项目 `/projects`
- 卡片网格：项目色条 + 名称 + 负责人 + 任务完成进度环 + 任务数；卡片点击进任务页项目筛选；编辑/删除（有任务时确认提示转移或保留任务为未分组）。

### 2.4 习惯 `/habits`
- 今日打卡卡片行：emoji + 名称 + streak 🔥 + 今日勾选。
- 下方每习惯一行近 7 天打卡格；添加/编辑弹窗（名称、emoji 选择、频率）。

### 2.5 番茄专注 `/focus`
- 大圆环倒计时（25:00），选中目标任务显示于上方；开始/暂停/重置；完成一段计入今日次数并 toast；休息段自动 5 分钟绿色调。

### 2.6 统计报告 `/summary`
- 日期范围快捷项（本周/本月/上季度/自定义）→ 生成：统计卡、状态分布饼图、7 天完成柱状图、项目进度表。
- 导出 Excel 按钮；「打印/PDF」按钮打开打印样式页触发 window.print()。

### 2.7 数据备份 `/backup` & 设置 `/settings`
- 备份：卡片列表（时间/大小）+ 创建/恢复/删除（恢复与删除需确认弹窗）。
- 设置：主题三选（浅/深/跟随系统）、快捷键速查表、关于信息。

## 3. 通用交互规范

| 场景 | 规范 |
|---|---|
| 成功操作 | 右上角 toast（3s 自动消失），文案具体（"已创建任务《xxx》"） |
| 失败操作 | 红色 toast + 原因；表单不丢输入 |
| 删除 | 二次确认弹窗（危险红按钮）；任务删除支持 toast 内「撤销」（前端暂存 5s） |
| 加载 | 骨架屏（卡片/列表形状），禁止白屏 |
| 空状态 | 插图 + 一句话 + 主行动按钮（如"新建第一个任务"） |
| 键盘 | `N` 新建（聚焦快速添加）、`/` 搜索、`Esc` 逐层关闭弹层、输入框内快捷键失效 |
| 表单校验 | 标题必填即时提示；日期/枚举用受控组件约束 |
