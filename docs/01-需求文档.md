# 个人规划中心 v2.0 — 需求文档（需求确认）

> 版本：v2.0 ｜ 日期：2026-09-19 ｜ 状态：已确认（用户委托全流程自动化执行）

## 1. 背景与目标

现有「个人工作事项管理工具」v1.0 具备任务/项目/进度/汇总/备份基础能力，但存在明显不足：

- **界面平淡**：单一列表页 + 表格，缺少看板/日历等高效视图，无深色模式，导航无高亮，操作反馈缺失。
- **功能单薄**：无标签、子任务、快速添加、多视图、番茄钟、习惯管理等主流效率工具标配。
- **使用繁琐**：添加表单内嵌页面顶部而非弹窗、无全局搜索、快捷键覆盖不全、删除/失败无提示。
- **工程隐患**：API 响应不校验、删除任务留下孤儿进度、备份恢复存在路径穿越风险、PDF 导出中文乱码。

**v2.0 目标**：对齐主流规划软件（Todoist / 滴答清单 / Things 3）的核心体验，做到「界面更美观、功能更全面、使用更简单」。

## 2. 调研结论（功能借鉴来源）

| 参考产品 | 借鉴点 |
|---|---|
| Todoist | 自然语言快速添加（`明天 写周报 #项目 @标签 !1`）、优先级色彩体系、键盘优先 |
| 滴答清单 | 日历视图、四象限视图、看板、番茄专注、习惯打卡、多视图一键切换 |
| Things 3 | Today / 即将到来 的今日聚焦组织方式、极简卡片设计 |
| Notion / Trello | 拖拽看板、项目化分栏管理 |

来源：Zapier《7 best to do list apps of 2026》、Wirecutter、PCMag、滴答清单官方帮助文档等。

## 3. 用户与场景

- 单用户本地部署的个人效率工具（无登录/多租户需求）。
- 典型场景：早晨看仪表盘安排当天 → 快速捕捉新任务 → 拖拽看板推进状态 → 周五生成汇总报告 → 日常番茄专注与习惯打卡。

## 4. 功能需求（v2.0 范围）

### F1 任务管理（核心增强）
- 任务字段：标题、描述、截止日期、优先级（高/中/低）、状态（未开始/进行中/待审核/已完成/已取消）、所属项目、**标签（多选）**、**子任务清单**、完成时间。
- **快速添加**：输入框支持自然语言解析——日期（今天/明天/后天/下周X/N月N日/12-25）、`#项目名`、`@标签`、`!1/!2/!3`（高/中/低优先级），回车即建。
- **筛选与搜索**：按项目/状态/优先级/标签/时间范围筛选；标题关键词搜索；全局快捷键 `/` 聚焦搜索。
- **排序**：截止日期/优先级/创建时间，升序降序。
- **分组显示**：按日期（逾期/今天/明天/本周/以后/无日期）或按项目/状态分组。

### F2 多视图
- **列表视图**：分组任务列表，支持批量状态切换。
- **看板视图**：按状态分栏，**拖拽改状态**（@dnd-kit）。
- **日历视图**：月历网格按截止日期展示任务，点击查看详情。
- **四象限视图**：紧急×重要矩阵，点击象限格查看/切换任务归属（自动映射优先级与截止日期）。

### F3 任务详情侧滑面板
- 右侧滑出式面板：查看/编辑全部字段、子任务增删勾选、进度记录时间线、快捷完成/删除。
- 替代 v1 的独立详情页，列表中点击任务即弹出，不离开当前视图。

### F4 仪表盘（首页重构）
- 时段问候 + 今日日期；**今日聚焦**（今天到期任务）、**即将到期**（未来 7 天）清单。
- 统计卡：总任务/今日待办/已完成/进行中；近 7 天完成趋势图（recharts）；项目进度条概览。

### F5 项目管理
- 项目新增**颜色标识**；卡片显示任务完成进度条与统计；项目下任务一键筛选。

### F6 统计报告
- 时间范围汇总：完成率、状态/优先级分布图、项目进度表。
- 导出：Excel（xlsx，保留）；PDF 改为**打印友好报告页 + 浏览器打印**（修复 v1 中文乱码）。

### F7 番茄专注（新增，轻量）
- 选择任务 → 25 分钟专注 / 5 分钟休息倒计时 → 完成专注计数；今日专注次数统计。

### F8 习惯打卡（新增）
- 习惯：名称 + emoji 图标 + 频率（每天/每周 N 次）；今日一键打卡；**连续天数 streak**；近 7 天打卡格。

### F9 数据备份（保留 + 加固）
- 创建备份/恢复/删除；修复路径穿越漏洞；恢复流程安全化（先关连接再覆盖再重连）。

### F10 设置与全局体验
- **深色/浅色/跟随系统**主题切换，持久化。
- 全局 Toast 通知（成功/失败/删除撤销提示）、统一确认弹窗、空状态与骨架屏、404 页。
- 快捷键：`N` 新建任务、`/` 搜索、`Esc` 关闭弹层。
- 导航当前路由高亮；移动端响应式侧边栏。

## 5. 非功能需求

- 数据兼容：v1 的 SQLite 数据（3 项目/4 任务/1 进度）升级后**无损保留**。
- 性能：个人数据量级（<10k 任务），接口无需分页，但需索引排序字段。
- 安全：API 输入校验（枚举/类型/长度），修复路径穿越；渲染用户内容防 XSS。
- 可维护：前后端共享枚举常量；统一 API 客户端与错误处理。

## 6. 验收标准（测试环节逐条核对）

1. 旧数据升级后完整可见；新字段（标签/子任务/完成时间）可用。
2. 快速添加一句话（含日期/#项目/@标签/!优先级）正确创建任务。
3. 看板拖拽改状态且刷新后持久；日历/四象限视图数据正确。
4. 详情侧滑面板可完成编辑/子任务/进度记录/删除全流程。
5. 深色模式切换即时生效且刷新后保持。
6. 汇总报告图表与导出 Excel 正常；打印报告中文无乱码。
7. 番茄钟计时与今日计数正常；习惯打卡与 streak 计算正确。
8. 备份创建/恢复/删除正常；路径穿越尝试被拒绝。
9. 全部 API 自动化测试通过；`tsc` 类型检查零错误；`vite build` 成功。
10. 浏览器 GUI 走查：主要页面无控制台报错、无布局破损、交互流畅。
